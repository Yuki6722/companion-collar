# Pre 提示稿（约 4 分钟口播 + 1 分钟演示）

> 用途：**演示/路演的提示稿**（cue sheet），不是逐字稿。三节分别对应「产品定义 / 用户调研 / 痛点与解法」。

## 0 · 开场（15 秒）

> 「我们做的是一件很小的事。**你上班的时候，它经历了什么；以及，它是不是正在慢慢变化。**」

〔停顿一秒，再上第一张图：3D 房间里的猫 + 右栏手机〕

**一句话产品定义**：给**白天不在家的养宠人**，一个「**离家事件流 + 基线哨兵**」——把「我不在家时它怎么样」从猜，变成一份**可核查的记录**。

---

## 1 · 产品定义（45 秒）

**① 我们帮谁**：在外工作的年轻养宠人。白天 8–10 小时不在家，回家只看得见宠物「现在」的样子。

**② 通过什么产品**：
- **项圈**（形态方案 + 传感器 + 前端摄像头）——不造真机，本轮交付规格与形态
- **手机 App 四模块**：实时 / 事件流 / 健康 / 档案
- **Web 演示站**：3D 家居场景 + 狗版场景，可扫码直接看

**③ 解决什么问题**：我们把「了解宠物感受」拆成四个问题，然后**只回答其中两个**。

| 问题 | 能否回答 | 依据 |
|---|---|---|
| ① 它现在感觉如何？ | ❌ 答不了 | 动物情绪体验不可直接测量（Mendl et al. 2010） |
| ② **我不在时发生了什么？** | ✅ 能答 | 抓挠/摩擦/碰撞/甩头/姿势改变/发声/环境噪声，都是可测的**事件** |
| ③ **它在慢慢变化吗？** | ✅ 能答，**且这是主人的盲区** | PLOS ONE 2026（n=647）+ AAFP 指南 |
| ④ 我家环境够不够？ | ✅ 能答（辅助模块） | AAFP/ISFM 五大支柱 |

> 收束句：「**市面上的产品都在回答第 ① 个问题——这正是它们答不好的原因。** 我们只回答 ② 和 ③。」

## 2 · 用户调研（60 秒）

### 2.1 市场（30 秒）

- **池子够大**：2025 年中国城镇犬猫消费 **3126 亿元**（+4.1%），单只犬年均 **3006 元**。
- **但结构里没有「理解宠物」这一项**：食品 53.7% / 医疗 27.6% / 用品 12.2% / 服务 6.5%。
- **人群正好是手机端**：宠主中 90 后 **42.7%**、00 后 **26.3%**。
- **付费行为已被验证过**：2026 年初一款「猫咪语言」App 登顶 iOS 付费榜，同类订阅 12–68 元/月。
  〔提示：说的是「愿意为更懂宠物付费」这件事真实存在，不是拿它证明我们的成本结构。〕

### 2.2 需求证据：两条独立路径，同一个结论结构（20 秒）

| 证据 | 说了什么 |
|---|---|
| PLOS ONE 2026，n=647（**犬**研究） | 主人对**明显**信号识别率 90%，但对**细微**信号**不优于从不养狗的人** |
| PDSA PAW 2024（YouGov，连续 14 年，全国代表性） | **95%** 的猫主人自认「已了解如何为猫提供合适环境」，但 **42%** 的英国猫与另一只猫同住，约 **180 万只**可能因同居伙伴而处于应激 |

〔口径纪律，主动说出来更可信〕：第一条是**犬**的研究，作者未主张可外推到猫；17 项征象里只有 3 项有差异。猫侧的替代证据是 Enomoto 2020——**未被引导时，DJD 疼痛清单敏感度只有 55%，被引导后 99%**。

→ **这就是产品形态的依据**：不是「替主人判断」，而是「**给主人一个引导性的问题**」。

### 2.3 目标用户画像（10 秒）

> **小林，26 岁，一线城市一居室合租，朝九晚七 + 偶尔加班；养一只 3 岁的猫（或一只柴犬）。**
> 手机不离手，愿意为宠物订阅付费；每天出门前会看一眼它，晚上 8 点回家只能看到它「现在」的样子。
> 她的焦虑不是「它今天开不开心」，而是「**我走了 10 个小时，它有没有出事 / 是不是在慢慢变差，而我一直不知道**」。

〔诚实边界，一句话带过〕：这个画像是**基于上述公开证据 + 团队假设构建**的，不是访谈结果；我们的前后测样本只有 5–10 人，明确标注非代表性。

### 2.4 市场空位（10 秒）

逐页核对 **22 个在售产品**之后：
- 摄像头型（PetCam / CW-01 等）**只做影像与事件通知**，不测生命体征；
- 传感型（PetPace / Tractive / Dinbeat UNO 等）**只做生命体征**，不带摄像头；
- **没有一款同时具备两者**；也**没有一款把「设备发现异常」自动接到「兽医介入」**。

## 3 · 痛点与解决方法（60 秒）

### 痛点一：能力错觉——「自认懂，其实读不准」
- 证据：95% 自认已了解环境需求 vs 实际 42% 多猫同住；引导后敏感度 55% → 99%。
- **解法**：**不给绝对阈值判断，只给「相对它自己基线」的变化。**
  稳健基线（中位数 / MAD）+ 置换检验 + 持续性判据；只有效应量、显著性、持续性**三者同时满足**才报「值得注意」。
  **「没有变化」是合法且必须能输出的结论。**

### 痛点二：无人时段是数据黑洞
- **解法**：**离家事件流**——按主人不在家的时段切窗口，输出每类事件的**次数与每小时速率、与自身基线的比值**、噪声与发声的同期配对。
  措辞只描述**事件与比值**，不描述感受。

### 痛点三：渐变看不见（AAFP：主人被问引导性问题前，并未意识到逐渐发生的变化）
- **解法**：**漂移报告**（按严重度排序）+ **项圈相机**（环境影像记录，用来判断它在哪）。
  渐变是跨天跨周才显形的，所以「没人在家」不是缺陷，反而让设计回到证据最强的两个方向。

### 痛点四：告警没人接
- **解法**：不接阈值告警，做「**趋势 → 分诊问题 + 转诊路径**」（ACVIM 共识里唯一有背书的居家预警协议是睡眠呼吸频率 <30 次/分，而它靠人数、不靠设备）。

### 收尾：三条硬边界（一句话一条，别展开）
1. **不做头显 VR**——iOS Safari 全版本不支持 WebXR，而主力用户在手机。
2. **不做声音语义翻译**——猫的焦虑发声与发情声相似，标准化翻译可能造成危险误判。
3. **不检测触觉感受**——触觉器官在面部触须与爪垫，项圈在颈部，这是物理错配。
〔最后一句，务必说〕**全部数据为仿真，不构成兽医诊断依据；健康问题请找执业兽医。**

## 4 · 现场演示动线（60 秒，按这个顺序点）

1. **默认页** → 3D 房间里的猫在自己活动 ＋ 右栏 iPhone 机模（画面与手机**共用同一条时间线**）。
2. **事件流页** → 每 5 分钟一条 + 喝水/进食/玩耍/砂盆/抓挠/躲藏次数。
3. **健康页 → 点左栏「抽搐」** → 画面演一段；心率呼吸因体动不可采信而**划线标红**；体表温**变红并升高约 0.5–0.8 °C**；弹出「宠物状态异常」，正文**逐条列出证据**（哪条通道、当前值、参考值、偏离多少）+ 边界句 + 转诊路径。
4. **档案页** → 改品种/年龄 → 数据按新档案重建。
5. **备选**：`#/vitals`（读数 vs 真值的分离）或 `#/dog`（同一套机制的狗版）。

## 5 · 最可能被问的三个问题

| 问 | 答（照这个方向） |
|---|---|
| 「你凭什么说主人看不出来？」 | 两条独立证据：PLOS ONE 2026（荷兰，n=647）与 PDSA PAW 2024（英国，连续 14 年）。**并主动交代口径限制**（犬研究、只有 3 项有差异、原文未测「误读为应激」的比例）——不交代反而会被追问。 |
| 「数据是真的吗？」 | 全部仿真，而且**带已知真值**：没有真硬件时，唯一能证明分析层正确的方法就是造一个知道答案的数据源。**不构成诊断依据。** |
| 「和市面项圈有什么区别？」 | 22 个在售产品逐页核对：没有一款同时有摄像头与生命体征，也没有一款把异常接到兽医。而且我们的核心不是传感器堆料，是**个体基线 + 变化叙事**。 |

## 6 · 措辞红线（说错一句就丢分）

| ❌ 不要说 | ✅ 改说 |
|---|---|
| 还原宠物视角 / 读懂宠物 | 环境影像记录 + 按个体基线检测变化 |
| 情绪识别 / 检测焦虑 | 行为事件统计 / 提示生理变化（非诊断） |
| 诊断 / 治疗 / 临床级 | 提示可能值得关注的生理变化 + 转诊路径 |
| 体温预警 / 换算成核心温 | 展示体表温度相对自身基线的变化 |
| 项圈能测触觉感受 | 触觉相关身体事件（抓挠、摩擦、碰撞、甩头） |
