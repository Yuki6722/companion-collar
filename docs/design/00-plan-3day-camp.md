# 「基线哨兵 + 离家事件流」3 天 Camp 开发计划

> **状态**：已批准（2026-10-02），v2。方向由「感知参数可视化」调整为「基线漂移检测 + 离家事件叙事」。
> 依据：三份研究报告的交叉结论，见 [`../research/`](../research/)。

---

## 0. 一句话定位

> **你上班时，它经历了什么；以及，它是否正在慢慢变化。**

面向**在外工作的年轻养宠人**：白天不在家，不知道宠物的健康状况。

---

## 1. 为什么是这个方向

### 1.1 「了解宠物感受」其实是四个问题，只有一个答不了

| 问题 | 能否回答 | 依据 |
|---|---|---|
| ①「它现在感觉如何？」 | ❌ **不可回答** | Mendl et al. 2010：动物情绪的意识体验**不可直接测量**，只能间接推断 |
| ②「我不在时发生了什么？」 | ✅ 可回答 | 事件检测（IMU）、环境噪声、发声计数均为可测**事件** |
| ③「它在慢慢变化吗？」 | ✅ 可回答，**且这是主人的盲区** | PLOS ONE 2026（n=647）：主人对**明显**信号识别率 90%，对**细微**信号不优于从不养狗者；AAFP 指南：「许多客户在被问到引导性问题前，并未意识到逐渐发生的变化」 |
| ④「我家环境够不够？」 | ✅ 可回答，证据最强 | AAFP/ISFM 五大支柱为同行评审框架（本版降为辅助模块） |

**本项目只回答 ② 和 ③。** 市面产品都在答 ①，这正是它们答不好的原因。

### 1.2 为什么「主人不在家」反而是优势

主人不在场，意味着产品**不能**依赖实时曲线与即时判断——而这恰好把设计推向两个证据最强的方向：

- **事件流**：不要求主人在场，只要求事后可读
- **漂移检测**：本来就需要跨天跨周的数据，实时盯着反而看不出来

### 1.3 关键证据

| 证据 | 用途 |
|---|---|
| PLOS ONE 2026（n=647）：主人漏掉**细微**疼痛信号 | 立项论据：痛点结构是「能力错觉」而非「能力缺失」 |
| AAFP：「被问到引导性问题前未意识到渐变」 | 直接支持「按个体基线检测漂移」 |
| PetPace 自身定位「按个体基线而非平均值」 | 业界已在做基线化，但没人把它做成「变化叙事」 |
| 噪声应激有可测生理链（行为 + 唾液皮质醇 + 尿液催产素） | 事件流中环境噪声与发声的配对**可验证** |
| Dinbeat UNO 已能测 ECG／心率／呼吸／体温／活动／体位／**发声** | 真机路径的能力上限参照 |
| AJVR 2024：消费级可穿戴在能量消耗上**不可靠** | 因此本项目**不做热量估算**，只做「相对自身基线的变化」 |

## 2. 硬约束（违反即返工）

| 约束 | 依据 |
|---|---|
| **不做头显 VR** | 队友2：WebXR 在 iOS Safari 全版本不支持 |
| **不做声音语义翻译** | 队友2：猫的焦虑发声与发情声相似，标准化翻译可能危险误判 |
| **不提供触觉感受检测** | 仅可交付「触觉相关身体事件」（抓挠／摩擦／碰撞） |
| **不提供生理读数用于临床** | 全部数据为仿真；不构成兽医诊断依据 |
| **不显示绝对数值判断，只显示相对基线的变化** | AJVR 2024 证伪了消费级绝对精度；基线化是唯一站得住的方式 |
| **不显示热量／能量消耗** | 同上，该指标已被同行评审研究直接质疑 |
| **每个参数带证据等级** | 见 [`02-evidence-policy.md`](02-evidence-policy.md) |
| **措辞纪律由 CI 强制** | 禁词扫描，命中即构建失败 |

## 5. 核心算法（决策完整）

### 5.1 稳健基线
- `median(xs)`、`mad(xs)`（原始中位绝对偏差）、`sigma = 1.4826 × mad`（正态下等效标准差）
- **最小样本数** `MIN_BASELINE_SAMPLES = 30`；不足返回 `null` → UI 显示「数据不足」而非猜测
- `robustZ(x, b) = (x − b.median) / b.sigma`
- **退化保护**：`sigma < 1e-9`（常量信号）时 `robustZ` 返回 0，并标记 `degenerate: true`

### 5.2 漂移检测
输入基线窗口（较早）+ 近期窗口（较晚），逐指标输出：

| 字段 | 定义 |
|---|---|
| `deltaRobust` | `(recentMedian − baselineMedian) / baseline.sigma`，稳健效应量 |
| `direction` | `up`／`down`／`none` |
| `severity` | `\|delta\| < 0.5` → `none`；`0.5–1.0` → `watch`；`≥ 1.0` → `notable` |
| `pValue` | **置换检验**（1000 次重排后重算中位数差） |
| `sustainedPct` | 近期样本中越过 `baselineMedian ± 1σ`（沿漂移方向）的比例 |
| `sustained` | `sustainedPct ≥ 0.6` —— 区分**持续漂移**与**单次尖峰** |

**报 `notable` 必须同时满足**：`|delta| ≥ 1.0` **且** `p < 0.05` **且** `sustained`。
只满足部分则降级为 `watch`。**「无漂移」是合法且必须能输出的结论。**

### 5.3 离家事件流
- 按 `awaySchedule` 切分离家窗口
- 每窗口输出：各事件类型计数与**每小时速率**、与全期基线速率的比值、环境噪声峰值与持续时长、噪声↔发声同期配对
- **异常窗口**：某类事件速率 ≥ 基线 2 倍且计数 ≥ 3
- 措辞一律描述**事件与比值**，不描述感受

### 5.4 仿真器：注入漂移
在既有四场景上增加 `drift: { metric, magnitude, startStep }`：
- 在指定步数后对目标指标叠加**渐进偏移**（线性斜坡，非阶跃），使「渐变检测」有可验证对象
- `truth.injectedDrift` 记录真值 → 断言检测器能还原方向与量级

## 8. 验证设计

**主命题**：观看漂移报告后，受试者对**「哪些指标正在变化」**的识别率从前测 X% 提升到后测 Y%。

- **为什么是窄命题**：队友2 报告指出「以视角换理解 → 行为改变」这条链**无任何直接研究**（置信度 58%）。因此只测**即时识别率**这个可证伪指标
- **流程**：前测（给一张原始数据表，问「哪些在变」）→ 使用应用 → 后测（同数据结构，顺序打乱）
- **样本**：5–10 人，方便抽样，**明确标注非代表性**
- **诚实边界**：结果页须写明「n 小、无对照组、仅测即时识别率，不代表长期行为改变」

## 9. 明确不做

- 不做头显 VR；不做声音语义翻译；不做触觉感受检测
- **不做诊断、不做情绪判断、不做 AI 情绪识别**
- **不做热量／能量消耗估算**（AJVR 2024 已证伪消费级精度）
- 不宣称提升宠物健康或长期福利
