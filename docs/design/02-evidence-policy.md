# 证据政策与措辞纪律

> 本文件定义本项目**如何对待证据**。它是三份研究报告交叉结论的制度化，也是产品可信度的来源。
> 本文件带有检查豁免标记，因为它必须能写出禁词本身。

---

## 1. 为什么需要这份政策

三份报告在核查中反复遇到同一个模式：**技术能力被当作效果证据使用**。

| 常见宣称 | 证据现状 |
|---|---|
| 「能监测心率、呼吸、体温」 | 功能存在可核实；**精度**被同行评审研究（AJVR 2024）直接质疑 |
| 「第一视角，从毛孩子视角出发」 | 营销语言。帧率低于猫闪烁融合频率、视野朝向不同、无嗅觉通道 |
| 「检测宠物健康状态」 | 可检测**指标**；不能检测或诊断"健康状态"本身 |
| 「检测触觉／情绪感受」 | 无任何产品或研究支持；颈部形态下**物理不成立** |
| 「科学设计，为犬猫优化」 | 设计原则可能有依据；**效果**普遍缺乏第三方验证 |

因此本项目采取一条方法论立场：**只宣称可证伪的事。**

## 2. 证据等级

```ts
type Tier = 'strong' | 'moderate' | 'weak' | 'unverified' | 'disputed'
```

| 等级 | 含义 | UI 呈现要求 |
|---|---|---|
| `strong` | 多项独立同行评审证据一致 | 正常展示数值 + 来源 |
| `moderate` | 单项研究或权威综述汇总表 | 展示数值 + 标注「单一来源」 |
| `weak` | 二手材料、教学讲义、工程经验值 | 展示数值 + 标注「弱证据」 |
| `unverified` | **未能取得可靠来源** | **不得展示具体数值** |
| `disputed` | 来源之间存在冲突 | **必须展示为区间** + 「来源冲突」提示 |
| `inference` | 由其他事实推导，非直接研究结论 | 标注「推断」 |

**类型层保障**：凡面向用户展示的参数值，其类型必须携带 `EvidenceTag`。没有证据标签的参数**无法通过类型检查**——这不是约定，是编译期约束。

## 3. 当前已知的冲突与缺口（不得擅自合并成单一数字）

### 3.1 四处 `disputed`

| 参数 | 冲突双方 | 处理方式 |
|---|---|---|
| **猫闪烁融合频率** | 58 Hz（Loop & Frey 1982，同行评审直接行为学测量，正常猫单眼）｜ 70–80 Hz（兽医继续教育材料） | 显示区间 58–80 Hz，标注来源冲突 |
| **猫听阈** | 58 Hz–75 kHz（Laboratory Animal Research 2023 汇总表）｜ 45–64 kHz（常见引用） | 显示两个区间，不作裁决 |
| **猫视锥数量** | 2（主流动物视觉文献，二色视觉）｜ 3（兽医继续教育材料） | **只用稳健表述**：「色觉显著不同于人类三色视觉」 |
| **犬闪烁融合频率** | 行为学法结论远高于 ERG 法 | **不给数字**（方法学依赖过强，样本仅 4 只比格犬） |

### 3.2 一处 `unverified`

- **犬视野 240°–250°**：广泛流传，但三份报告均**未取得一手来源**。→ **不使用该数字。**

### 3.3 一处 `weak`

- **犬嗅觉量级**：仅 Tier 3 教学讲义（嗅上皮面积、受体数量）。→ 只作方向性结论「高于人类一到两个数量级」，**不用具体数值**。

### 3.4 一处 `inference`

- **颈部项圈无法检测触觉感受**：由「触觉器官位于面部触须与爪垫」这一 `strong` 事实推导，本身**不是**直接研究结论。→ UI 必须标注为推断。

## 4. 措辞纪律（由 CI 强制）

`pnpm check:claims` 扫描 `packages/`、`apps/`、`docs/`、`scripts/` 与根目录文档，命中禁词即**构建失败**。

### 4.1 禁词表

| 禁词 | 原因 |
|---|---|
| 检测触觉感受 | 触觉器官在面部与爪垫，颈部项圈物理上测不到 |
| 还原宠物视角 / 还原宠物所见 / 宠物所见 | 帧率、视野、嗅觉三通道都不等价 |
| 宠物视角相机 | 准确说法是「环境影像记录仪」 |
| 翻译宠物语言 / 猫语翻译 | 专家已指出标准化翻译可能造成危险误判 |
| 读懂宠物 | 不可证伪的承诺 |
| 宠物情绪识别 | 动物情绪体验不可直接测量（Mendl et al. 2010） |
| 沉浸式代入 | 本项目不做头显 VR |
| 诊断 / 治疗 | 非医疗器械；除非在否定语境中作为免责声明 |

### 4.2 两种豁免机制

1. **行级否定标记**：同一行含 `不构成`／`不是`／`禁止`／`❌`／`无法` 等，视为边界说明或免责声明，放行。
2. **文件级豁免**：文件前 15 行含 `claims-check:ignore-file` 者整份跳过。
   用于**本身就是政策文本**的文件：本文件、`AGENTS.md`、`scripts/check-claims.mjs`。
   此外 `docs/research/` 整目录豁免——归档的第三方与历史报告需要能批判性地讨论这些词。

### 4.3 允许的宣称（白名单）

只有以下宣称可以出现在面向用户的文案里：

- 可视化猫的视野与身体尺度
- 按证据等级展示听阈范围
- 核查居家资源是否符合权威指南
- 提示可能值得关注的生理变化（非诊断）
- 环境影像记录

## 5. 方法论立场（写给自己看）

1. **主动承认先行工作。** iStrayPaws（VRST 2024）已用同行评议证明第一人称动物 VR 可显著提升共情；2025–2026 年已有一批非人类具身作品。主动说明「我们知道站在谁的肩膀上、也知道窗口在收窄」，比被质疑后承认更有说服力。
2. **主动引用批评概念。** 动物行为学界对拟人化有真实争议（Burghardt 的「批判性拟人化」）。把质疑转成专业性展示，而不是回避。
3. **失败时信息量最大。** 验证写成窄命题（资源缺口识别率），若连识别率都不提升，整个「以视角换理解」的假设就该被重新审视——这比一个模糊的成功更有价值。
4. **不猜。** 用户未回答的问题一律返回 `unknown`，绝不默认合格。
