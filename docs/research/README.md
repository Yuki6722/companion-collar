## 01 · 项圈多模态感知研究

**归属**：本项目作者（本地报告）

| 文件 | 说明 |
|---|---|
| [`collar-multimodal-perception.html`](01-collar-multimodal/collar-multimodal-perception.html) | v2.0 网页版报告。自包含单文件，含摘要、学界研究、产品对比矩阵、综合洞察、结论与 45+ 条已核验引用 |
| [`sensory-translation-litreview.md`](01-collar-multimodal/sensory-translation-litreview.md) | 跨物种感官转译文献调研（324 行）。逐条标注证据等级，含第 7 节「无法验证」清单 |

**对本项目的三条关键结论**

1. **产品空白**：摄像头型项圈（PetCam / CW-01 / Kentfaith / Vbestlife）只做影像与定位；传感型项圈（Dinbeat UNO / PetPace / Tractive）只做生命体征。**没有一款同时具备两者**——受体积、功耗、发热、佩戴舒适度四重约束。
2. **触觉错配**：犬的面部触须是独立感觉器官，每根有高度神经支配的专用毛囊；修剪在德、奥、瑞受动物福利法禁止。**触觉器官在面部与爪垫，项圈在颈部**，因此颈部项圈物理上无法检测触觉感受，只能检测触觉相关身体事件。
3. **摄像头不等价于宠物视觉**：猫的临界闪烁融合频率约 58 Hz，而消费级摄像头多为 30 fps；项圈摄像头朝向与宠物视野不同；无嗅觉通道。

**最相关的研究对标**：Dinbeat UNO 是目前传感器最全的产品（心电图 / 心率 / 呼吸频率 / 体温 / 活动 / 体位 / **发声**），为兽医专业级 B2B 销售，未公开 API。

## 02 · 同一屋檐，不同世界（猫狗感知与体验设计研究）

**归属**：Inkstone00 · 源仓库 [Inkstone00/pet-perspective-research](https://github.com/Inkstone00/pet-perspective-research) · 线上 [inkstone00.github.io/pet-perspective-research](https://inkstone00.github.io/pet-perspective-research/)

**导入方式**：整站导入 —— 该报告的正文内容在 `app.js` 中由客户端渲染，纯文本抓取只能得到页头，因此必须保留整站文件才能完整阅读。

| 文件 | 说明 |
|---|---|
| `index.html` / `app.js` / `styles.css` | 报告站点（内容在 app.js 内） |
| `pet-perspective-concept.png` | 概念图（AI 生成，非动物实际视觉） |
| `.nojekyll` | GitHub Pages 配置 |

**核心贡献：共用体验机制，分开感知参数**

- 可以共享的是**设计问题**：我能获得什么信息？我能去哪里？我能否选择接近或离开？
- 不能共享的是**未经验证的感官数值与情绪结论**。
- **猫分支**：安全位置与自主接近 —— 藏身处、退避路线、人的接近方式。
- **狗分支**：声音线索与主动探索 —— 声源、离开声源的路径、局部嗅闻线索。
- 明确边界：「以上为原型架构建议，不是猫狗行为的固定分类；猫也会探索和响应声音，狗也需要退避与选择。」
- 交付定位：基于动物感知与行为研究的**桌面第一人称体验**，探索未来 VR 的交互构想；**Camp 重点是体验表达、可执行选择和清晰的证据边界，不是证明长期照护效果**。

原文表述：「基于研究的设计转译，**不是动物主观体验的复刻**。」

## 03 · 《伴侣视角》立项深度研究报告

**归属**：Cily13141 · 源仓库 [Cily13141/companion-perspective](https://github.com/Cily13141/companion-perspective) · 线上 [cily13141.github.io/companion-perspective/research](https://cily13141.github.io/companion-perspective/research/)

**导入方式**：导入研究产物（Markdown / JSON 源文件）。已跳过 1.9 MB 的报告 PDF 与构建后的 HTML 副本，可经上方链接获取。

| 文件 | 说明 |
|---|---|
| `research-report.md` | **主报告**（75.7 KB，35 个来源，综合置信度 80%） |
| `science.json` | 结构化科学参数数据 |
| `team2-proposal-transcript.md` | 立项文档逐页转录 |
| `prototype-readme.md` | 原型说明 |
| `README.md` | 源仓库说明 |

**对本项目最关键的六条结论**

1. **痛点被同行评审量化，且结构是「能力错觉」而非「能力缺失」**：PLOS ONE 2026（n=647）显示养犬者识别宠物**细微**疼痛信号的能力**并不优于非养犬者**。⚠️ **三点必须照原文写**：① 这是**犬**研究，作者**未主张**可外推到猫；② 17 项征象中**只有 3 项**在两组间有差异，且「僵住」一项 **P=0.007 高于该文自己的 Bonferroni 阈值 0.003，只能算趋势**；③ 该文**没有测量**「误读为应激」的比例——「系统性把转头避开/僵住误读为应激」只是作者的**推测句**，本项目不得当作结论。**猫侧的替代证据**见 [`06`](06-cat-acute-observables.md)：未被引导时 DJD 疼痛清单敏感度 55%（Enomoto 2020）。
2. **第二份独立证据（英国 PDSA PAW 2024，YouGov 全国代表性调查，连续 14 年）**：95% 的猫主人自认已了解如何为猫提供合适环境，但 42% 的英国猫与另一只猫同住，约 180 万只猫可能因同居伙伴而应激。
3. **「环境舒适度」在专业上不是感受，而是可核查的资源清单** —— AAFP/ISFM 健康猫科环境五大支柱：安全的地方；多个且相互分离的关键环境资源；玩耍与捕猎机会；积极一致可预测的人宠互动；尊重嗅觉重要性的环境。
4. **头显路线的硬约束**：WebXR Device API 在 iOS Safari **全版本不支持**；90 fps / 20–30 ms 运动到光子延迟是基线，72 fps 即可诱发不适。
5. **先行工作已被占位且赛道正在收窄**：iStrayPaws（VRST 2024）已用同行评议证明第一人称动物 VR 可显著提升状态共情与特质共情；2025–2026 年已涌现一批非人类具身作品（狗的耳朵触觉具身、鸟的感知可穿戴、蜘蛛具身等）。
6. **最大证据缺口（置信度仅 58%）**：「以宠物视角观察自家环境 → 饲主行为改变」这条因果链**无任何直接研究**。因此验证必须写成窄命题。

**明确不建议**：加「翻译宠物在说什么」功能；把 VR 锁定为唯一机制；承诺「让饲主完全读懂宠物」。

## 04 · 猫健康监测（专项研究）

**归属**：本项目作者（本地报告）· 2026-10-02

| 文件 | 说明 |
|---|---|
| [`cat-health-monitoring.html`](04-cat-health-monitoring/cat-health-monitoring.html) | 网页版报告（52 KB，自包含单文件）。含摘要、猫正常参考区间、**指标临床价值排序表**、活动/睡眠监测验证、骨关节炎、佩戴可行性、产品对比矩阵、综合洞察、结论与 25 条引用 |

**本报告回答的问题**：像人类健康手环那样给猫做健康监测，可行吗？需要测什么、能测到什么？

**五条关键结论**

1. **「猫版健康手环」的类比在最关键处失效。** 人类手环成立的前提是最高价值的指标都能在**手腕一个位置**测到；对猫不成立——猫诊断价值最高的信号（**饮水量、猫砂盆使用、体重趋势、进食量**）发生在水碗、猫砂盆、秤、食盆，**不在颈部**。猫的等效物是**固定式传感器网络 + 周期性在家检测**，项圈是补充而非主体。
2. **活动与睡眠已被同行评审验证。** PLOS ONE 2020（n=61 家养猫，三轴加速度计 + 气压传感器）：活动量与跳跃次数随年龄显著下降，休息与睡眠时间显著上升，能准确区分休息与睡眠。**⚠️ 利益冲突须披露**：设备方 JARMeC 参与研究并持 pending 专利。
3. **骨关节炎是猫最被低估的问题，且不表现为跛行。** 影像学筛查：100 只随机选取的猫中 **92% 有影像学退行性关节病、91% 至少一处附肢关节受累**（Lascelles 2010, *Vet Surg* 39(5):535-544，n=100）；另一项 **n=100 只 ≥6 岁猫**的研究给出 **61% 至少一个关节有 OA、48% 多关节**（Slingerland 2011, *Vet J* 187(3):304-309）。最常见的表现是**跳跃能力下降（71%）与跳跃高度降低（67%）**——⚠️ 该两数出自 **n=28 的临床患病猫队列**（Clarke & Bennett 2006, *J Small Anim Pract* 47(8):439-445），是**队列内主人观察到的频率，不是患病率**。⚠️ **本项目不使用「14 岁以上 82% 有 OA」这一流传数字**：一手摘要中查无此值，只见于二手转引。
4. **项圈在猫身上有真实可行性问题。** JAVMA 有专门 RCT 分析猫项圈**失效时间**（含塑料卡扣项圈 176 只 / 32.7%）。此外**猫的心率参考区间存在来源冲突**（某兽医教育资源给 120–140 bpm，临床常见口径 140–220），且诊室应激会抬高读数——**这恰说明"家里测的静息基线"比诊所读数更有价值**。
5. **产品侧重心已不在项圈上。** 成熟品类是固定式的：猫砂盆监测（Purina Petivity、Whisker Litter-Robot、CATLINK）、微芯片识别的饮水机（Sure Petcare Felaqua，**逐只猫的饮水量**）、在家检测条与健康指示猫砂（PrettyLitter）。

**最可执行的建议**：把「**跳跃**」做成核心卖点——它是本报告找到的唯一「高临床价值 + 项圈独有可测 + 已有验证路径」的交集。同时明确划掉三件事：不做能量消耗估算（AJVR 2024 已证伪）、不做声音语义翻译、不做情绪判断。

**与主项目的关系**：本专项独立于「基线哨兵 + 离家事件流」计划，但为其**活动/跳跃指标提供了外部证据基础**，并支持「按个体基线检测漂移」而非绝对阈值判断的方法论选择。

## 05 · 家猫在宅行为谱系（2026-10-03）

**归属**：本项目作者（行为层证据底稿）

| 文件 | 说明 |
|---|---|
| [`05-cat-home-behavior-repertoire.md`](05-cat-home-behavior-repertoire.md) | 家猫在宅可观测行为谱系。含**行为 → 传感器 → 速率/时长 → 证据等级 → 来源**主表、24 小时节律、跳跃/抓挠/理毛/进食/躲藏各专项、以及「项圈看不到什么」的物理原因；30 条参考文献 |

**本报告回答的问题**：猫在家里有哪些动作？各自由哪种传感器可观测？典型速率与时长是多少？

**关键结论**

1. **「项圈 IMU 的姿势分类可信」是有条件的**：Smit et al. 2023（*Sensors* 23(16):7165，n=12，7 天连续录像）显示姿势可识别，但 **climbing / digging / allogrooming 的 true positive = 0**，且**抓挠被系统性误分类为理毛、必须合并**。项圈模型持续差于胸背带模型。
2. **「每天跳几次」「最大跳跃高度」没有一手来源**，属 `unverified`，本项目**不给数字**。已知的唯一跳跃数据是被实验者**主动诱导**的（Sharon 2020）。跳跃检测的物理下限是 **≥40 cm** 气压变化。
3. **24 小时节律是 `disputed`**：n=61 的研究显示日间/夜间静息时长有差异，而 n=5 的研究未检出总活动量的日节律。项目**只输出相对倾向权重，不输出峰值时刻**。
4. **「离家事件流」有直接受控证据支撑的通道只有「发声事件计数」一项**（Hare et al. 2025：主人不在场时 IRR ≈ 3.2）。活动量、抓挠、躲藏的变化方向目前都是**假设**。
5. 「只做自身基线、不做跨猫阈值」有 Migny et al. 2026 的一手支撑：**个体日剖面互不重叠**，作者明确主张需要个体化参考。

## 06 · 猫在疾病与急性痛苦下的居家可观察信号（2026-10-03）

**归属**：本项目作者（行为层证据底稿）

| 文件 | 说明 |
|---|---|
| [`06-cat-acute-observables.md`](06-cat-acute-observables.md) | 急性/疼痛的居家可观察信号清单、五个疼痛量表的归属差异、假阳性来源、急诊红旗、以及项圈物理上测不到的信号；54 条参考文献 |

**本报告回答的问题**：猫生病或急性不适时，在家能看到什么？哪些是项圈可能看见的？哪些根本看不见？

**关键结论**

1. **五项量表对「发声」的处理互相矛盾（`disputed`）**：Glasgow 量表与 2022 ISFM 指南把它算作征象，而 **UFEPS 短表明确删除该项、Feline Grimace Scale 完全没有该项**；AAHA 与 iCatCare 反而强调猫更少表现出明显疼痛（例如发声）。→ 本项目**不把发声当作独立征象**，只作「有声/无声」计数。
2. **「长时间不动」无法被可靠归因**：2022 ISFM 原文指出猫会在**恐惧**时减少移动并僵住。→ 这是本模型**最重要的假阳性来源**，已写入漂移报告的边界文案。
3. **主人漏报应按疾病分述**：猫侧可用的量化是 Enomoto 2020（未被引导时 DJD 疼痛清单敏感度 **55%**，已引导时 99%）与 Herrera 2026（CKD 猫中 **75.6%** 的排尿变化未被报告）。⚠️ 既有文档曾引用的 PLOS ONE 2026（n=647）是**犬**研究，且原文**未测量**「误读为应激」的比例，不可外推。
4. **诊室读数不能当基线**：呼吸频率诊室中位 **64**（28–176）vs 家中静息中位 **27** vs 午睡中位 **20**；心率门诊入口 **176±35**、检查室 195、处置区 226 bpm。
5. **项圈能力上限有已发表的量化**：Montout et al. 2025 用项圈加速度计预测早期退行性关节病，**AUC 0.78、敏感度 68% @ 75% 特异度**，且标签是主人报告（**代理标签而非金标准**）、**22% 佩戴猫被排除**。这条应当写进漂移引擎的预期性能与诚实边界。
