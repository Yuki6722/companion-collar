## 01 · 项圈多模态感知研究

**归属**：本项目作者（本地报告）

| 文件 | 说明 |
|---|---|
| [`collar-multimodal-perception.html`](01-collar-multimodal/collar-multimodal-perception.html) | v2.0 网页版报告。自包含单文件，含摘要、学界研究、产品对比矩阵、综合洞察、结论与 45+ 条已核验引用 |
| [`sensory-translation-litreview.md`](01-collar-multimodal/sensory-translation-litreview.md) | 跨物种感官转译文献调研（324 行）。逐条标注证据等级，含第 7 节「无法验证」清单 |

**对本项目的三条关键结论**

1. **产品空白**：摄像头型项圈（PetCam / CW-01 / Kentfaith / Vbestlife）只做影像与定位；传感型项圈（Dinbeat UNO / PetPace / Tractive）只做生命体征。**没有一款同时具备两者**——受体积、功耗、发热、佩戴舒适度四重约束。
2. **触觉错配**：犬的面部触须是独立感觉器官，每根有高度神经支配的专用毛囊；修剪在德、奥、瑞受动物福利法禁止。**触觉器官在面部与爪垫，项圈在颈部**，因此颈部项圈物理上无法检测触觉感受，只能检测触觉相关身体事件。
3. **摄像头不等价于宠物视觉**：猫的临界闪烁融合频率约 58 Hz，而消费级摄像头多为 30 fps；项圈摄像头朝向与宠物视野不同；无嗅觉通道。

**最相关的研究对标**：Dinbeat UNO 是目前传感器最全的产品（心电图 / 心率 / 呼吸频率 / 体温 / 活动 / 体位 / **发声**），为兽医专业级 B2B 销售，未公开 API。

## 02 · 同一屋檐，不同世界（猫狗感知与体验设计研究）

**归属**：Inkstone00 · 源仓库 [Inkstone00/pet-perspective-research](https://github.com/Inkstone00/pet-perspective-research) · 线上 [inkstone00.github.io/pet-perspective-research](https://inkstone00.github.io/pet-perspective-research/)

**导入方式**：整站导入 —— 该报告的正文内容在 `app.js` 中由客户端渲染，纯文本抓取只能得到页头，因此必须保留整站文件才能完整阅读。

| 文件 | 说明 |
|---|---|
| `index.html` / `app.js` / `styles.css` | 报告站点（内容在 app.js 内） |
| `pet-perspective-concept.png` | 概念图（AI 生成，非动物实际视觉） |
| `.nojekyll` | GitHub Pages 配置 |

**核心贡献：共用体验机制，分开感知参数**

- 可以共享的是**设计问题**：我能获得什么信息？我能去哪里？我能否选择接近或离开？
- 不能共享的是**未经验证的感官数值与情绪结论**。
- **猫分支**：安全位置与自主接近 —— 藏身处、退避路线、人的接近方式。
- **狗分支**：声音线索与主动探索 —— 声源、离开声源的路径、局部嗅闻线索。
- 明确边界：「以上为原型架构建议，不是猫狗行为的固定分类；猫也会探索和响应声音，狗也需要退避与选择。」
- 交付定位：基于动物感知与行为研究的**桌面第一人称体验**，探索未来 VR 的交互构想；**Camp 重点是体验表达、可执行选择和清晰的证据边界，不是证明长期照护效果**。

原文表述：「基于研究的设计转译，**不是动物主观体验的复刻**。」

## 03 · 《伴侣视角》立项深度研究报告

**归属**：Cily13141 · 源仓库 [Cily13141/companion-perspective](https://github.com/Cily13141/companion-perspective) · 线上 [cily13141.github.io/companion-perspective/research](https://cily13141.github.io/companion-perspective/research/)

| 文件 | 说明 |

| `science.json` | 结构化科学参数数据 |

| `prototype-readme.md` | 原型说明 |
| `README.md` | 源仓库说明 |

**对本项目最关键的六条结论**

1. **痛点被同行评审量化，且结构是「能力错觉」而非「能力缺失」**：PLOS ONE 2026（n=647）证明养犬者识别宠物细微疼痛信号的能力**并不优于非养犬者**，且系统性把「转头避开 / 僵住」误读为应激而非疼痛。
2. **第二份独立证据（英国 PDSA PAW 2024，YouGov 全国代表性调查，连续 14 年）**：95% 的猫主人自认已了解如何为猫提供合适环境，但 42% 的英国猫与另一只猫同住，约 180 万只猫可能因同居伙伴而应激。
3. **「环境舒适度」在专业上不是感受，而是可核查的资源清单** —— AAFP/ISFM 健康猫科环境五大支柱：安全的地方；多个且相互分离的关键环境资源；玩耍与捕猎机会；积极一致可预测的人宠互动；尊重嗅觉重要性的环境。
4. **头显路线的硬约束**：WebXR Device API 在 iOS Safari **全版本不支持**；90 fps / 20–30 ms 运动到光子延迟是基线，72 fps 即可诱发不适。
5. **先行工作已被占位且赛道正在收窄**：iStrayPaws（VRST 2024）已用同行评议证明第一人称动物 VR 可显著提升状态共情与特质共情；2025–2026 年已涌现一批非人类具身作品（狗的耳朵触觉具身、鸟的感知可穿戴、蜘蛛具身等）。
6. **最大证据缺口（置信度仅 58%）**：「以宠物视角观察自家环境 → 饲主行为改变」这条因果链**无任何直接研究**。因此验证必须写成窄命题。

**明确不建议**：加「翻译宠物在说什么」功能；把 VR 锁定为唯一机制；承诺「让饲主完全读懂宠物」。
