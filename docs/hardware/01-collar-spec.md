# 01 · 项圈规格与传感方案（心率 / 呼吸 / 体表温）

> **状态**：规格方案 + 仿真实现（第三阶段）。**不造真机**——本仓库的数据全部为仿真，
> 这一份文档是把「要做一个能测心率、呼吸、体温的项圈」这件事拆成可评审、可验证的工程条目。
> **证据底稿**：[`docs/research/01-collar-multimodal`](../research/01-collar-multimodal/collar-multimodal-perception.html)（产品与形态）、
> [`06`](../research/06-cat-acute-observables.md) 与 [`07`](../research/07-cat-acute-alerting/acute-alerting-research.html)（生理量与验证状态）。

---

## 0. 先写下这份规格**不能**承诺的事

下面四条不是免责套话，它们决定了本规格里每一个选型与每一句面向用户的措辞：

| 不承诺 | 原因（已核实） |
|---|---|
| 核心体温 | 项圈只能测颈部**体表温**；耳廓红外温与直肠温**无相关**（n=61，Kendall τ ≈ −0.01，平均偏差 −2.7 ± 1.44 °C，原文「cannot be recommended」）；另有研究认为耳温可替代 → `disputed`。**任何换算都是伪精度。** |
| 血压 | 测血压要么阻断动脉（袖带 + 多普勒/示波法），要么动脉置管。**项圈无法阻断动脉**——这是形态错配，不是精度问题。 |
| 呼吸/心率的精度等级 | **未检索到任何清醒居家猫上把项圈心率/呼吸对金标准验证的前瞻研究**。唯一的猫心肺穿戴验证是 20 只**麻醉**猫、20 分钟，且用的是**人用婴儿血氧袜**（心率 r=0.995、血氧 r=0.634）。 |
| 任何临床级/诊断用途 | 全部数据为仿真；读数不构成兽医诊断依据。任一提示都必须同时给出测量条件与转诊路径。 |

> 还有一条**形态**上的结论：多参数项圈与带摄像头的项圈各自都在 **60–100 g** 量级，
> 合一会显著超出体重 2% 的重量预算。这就是「摄像头与健康传感从未合一」的工程原因，
> 因此本规格**不含摄像头**。

## 1. 三通道的物理位置与选型

位置决定能力，所以先画位置，再谈器件。

| 通道 | 传感位置 | 主选型 | 备选 | 为什么是这个位置 |
|---|---|---|---|---|
| **心率** | 颈**侧**（左右各一电极） | **双干电极 ECG** | 颈部 PPG | ECG 靠电信号，不需要光学通路；Dinbeat UNO 走的是胸背带 ECG（兽医级），颈部形态是消费级的折中。PPG 在**有毛、皮肤松弛、且猫每分钟都在转头**的颈部可行性最低。 |
| **呼吸** | 颈**背**侧（随颈运动） | **IMU 胸廓微动**（六轴） | 胸阻抗（电极位置受限） | 呼吸在颈部只有微弱的胸廓传导，**必须限定在低体动窗口**；因此这一通道的产品价值来自"睡眠/静息时的节律变化"，而不是全天读数。 |
| **体表温** | 颈**腹**侧（贴皮） | **热敏电阻** | 红外非接触 | 贴皮测的是被毛表面温度。它随环境与被毛漂移，**不随核心温**——见 §0。另配一颗环境参考热敏，用于把环境耦合项标注出来。 |
| 附加（本阶段一并登记） | 颈背 | IMU（活动/姿势/抖动）、麦克风（发声**事件计数**）、气压计（跳跃高度） | — | 麦克风只做"有声/无声"计数，**不做语义**（硬约束）。 |

**采样与聚合**

| 项 | 取值 | 说明 |
|---|---|---|
| ECG 采样 | 200 Hz（睡眠档） | 干电极的接触噪声需要过采样后平均 |
| IMU 采样 | 50 Hz | 覆盖 5–20 Hz 抖动与呼吸运动 |
| 生理读数聚合窗口 | **60 s** | 与仿真一致（`VITALS_CONSTANTS.aggregationWindowS`） |
| 上报粒度 | 事件级 + 分钟级聚合 | 分子策略：原始波形不上云，只上"读数 + 有效性 + 条件" |

**分档采样（省电的核心手段）**：睡眠/静息段全采样；体动超门限时降采样并把该窗口标为不可用；
移位/接触不良时**停止上报读数**而不是上报坏值（仿真里对应 `rejected-out-of-range` 不写数值）。

## 2. 佩戴、福利与硬约束

| 条目 | 规格 | 依据 |
|---|---|---|
| 重量预算 | **体重 2%**（4.2 kg 猫 → 84 g） | 工程经验值，标 `weak`；`profile.ts` 的 `collarBudgetOf` 已实现 |
| 在售参照 | 多参数传感项圈 60 / 90 / 100 g；摄像头型项圈约 100 g | 厂商规格页与供应链物料，标 `weak` |
| 带长范围 | 由体重近似颈围推导（`strapMinMm`–`strapMaxMm`） | 同上 |
| **面部触须无干涉区** | 硬件**不得**进入面部触须扫掠的体积（本仓库在 3D 里把它画出来：`?collar=zone`） | 触须是**独立感觉器官**，德/奥/瑞动物福利法禁止为美观修剪；设备同理不得压迫、摩擦或遮挡 |
| 电极接触 | 干燥电极 + 导电硅胶 + 适度压力；需要短毛区 | 剃毛涉及福利与伦理审查，规格里把它列为需要兽医参与的决策，而不是默认做法 |
| 佩戴适应 | 必须做适应性观察（脱敏、逐步延长佩戴） | 设备重量与佩戴本身是真实的福利变量 |
| 防护 | 目标 IP66/IP68 量级 | 参照在售产品 |
| 电池 | 3.8 V 500 mAh 量级，充电 1.5 h 至 80% | 参照在售产品规格（`weak`，不作定价或续航承诺） |

## 3. 读数有效性的三个失效源（规格层面必须定义）

这一节是本规格与"普通硬件规格书"最大的区别：**它定义的是"读数什么时候不算数"**。

| 失效源 | 触发 | 处理 |
|---|---|---|
| **运动伪迹** | 体动指数超门限（心率 0.6 / 呼吸 0.25） | 该窗口标 `motion-artifact`，**不进入任何基线或统计**；界面划线展示 |
| **接触不良 / 项圈移位** | 探头离皮、项圈旋转或松紧变化 | 标 `poor-contact`；这一条**与体动无关**，必须单独建模（否则休息时会被当成"一定准"） |
| **超出量程** | 读数落在物理量程外 | 固件拒收，**不上报数值** |
| （第四类）**测量情境** | 诊室/陌生环境 | 不是失效，而是**条件标签**：读数必须带 `clinic` 等条件，跨条件比较一律拒绝 |

> 情境这一条有直接数据：健康猫在门诊入口 176 ± 35、检查室 195、处置区 226 bpm，
> 而家中静息区间是 120–140；呼吸频率诊室中位 64 vs 家中静息 27 vs 午睡 20。
> **读数的变化方向由情境决定，不由病情决定。**

## 4. 验证路线

### 4.1 已做（本阶段，仿真内自洽）

```bash
node packages/simulator/src/eval-vitals.ts --seed 42 --minutes 1440
```

它输出：三通道可用率与失效原因分布、体表温读数 vs 核心温真值的相关与拟合误差、
情境对照（同种子、同真值）、睡眠呼吸频率汇总。**它证明的是链路自洽，不是准确度。**

### 4.2 可以真做且成本最低：体表温 vs 直肠温同步采集

这是本项目唯一能"自己裁决一个 `disputed` 参数"的实验，而且不需要做整机：

- 场所：与兽医合作，在常规体检中同步采集（耳廓红外 + 颈部贴皮热敏 + 直肠温度计）；
- 样本：≥60 只成年猫，覆盖长毛/短毛、不同体型；
- 分析：Bland–Altman（偏差与一致性界限）+ Kendall τ/ICC；
- 判据：若与 Barton 2022 一致（无相关），则本规格的"不换算"立场被二次确认；
  若与 Sousa 2013 一致（可替代），**也必须先复现再改措辞**。
- 伦理：非侵入、无额外应激的测量才可以做；任何需要剃毛的方案须先过伦理审查。

### 4.3 真机整机验证（后续，需要硬件）

| 指标 | 参考标准（金标准） | 最小设计 | 分析 |
|---|---|---|---|
| 心率 / HRV | Holter ECG | 清醒居家猫 ≥20 只，同步 ≥6 h，跨睡眠与活动 | Bland–Altman + ICC；按条件分层报告 |
| 呼吸频率 | 同步录像人工计数 | 同批猫，取睡眠窗口（共识协议的同条件） | 同上；**必须先报告判读一致性** |
| 体表温 | 直肠温度计 | ≥60 只，一次同步 | 偏差 + 相关（即 4.2） |
| 佩戴与脱落 | 佩戴日志 | 依从性与脱落率目前**没有猫专属数据**，必须自己采 | 描述性统计 |
| 多猫个体归属 | 微芯片/视频 | 未验证 | 未验证则必须在界面标注 |

**分层是硬要求**：长毛/短毛、体况、年龄段必须分开报告——把不同毛型的误差平均掉，等于制造一个不存在的大样本。

## 5. 明确不做

- ❌ 核心体温读数（见 §0）
- ❌ 血压（物理不成立）
- ❌ 体温预警与任何急症级阈值告警（唯一有共识的居家阈值是**睡眠呼吸频率 >30**，且其原始做法是**人用眼睛数**）
- ❌ 临床级 / 医疗级等级宣称
- ❌ 摄像头合一（超重；且摄像头与健康传感的合一不是本阶段的目标）
- ❌ 能量消耗估算（AJVR 2024 已证伪消费级穿戴在该任务上的可靠性）
- ❌ 疾病判定
